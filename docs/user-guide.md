# Basalt 管理台（Console）用户手册

> 适用版本：v1.7.0 · 界面基线：32 视图（本文档与实际 UI 一一对应，由前端交付者编写）
> 面向读者：平台管理员 / 业务用户 / 运维人员

---

## 1. 开始使用

### 1.1 登录

浏览器打开 Console 地址（默认 `http://<host>:8080/`），输入用户名与密码登录。

- 初始管理员账号 `admin`，初始密码见部署说明（安全基线要求首启显式配置 `BASALT_BOOTSTRAP_ADMIN_PASSWORD`）。
- 若服务端配置了钉钉登录（`BASALT_SSO_DINGTALK_*`），登录页会出现**钉钉登录**按钮：点击后跳转钉钉扫码，成功后自动返回控制台并登录；提示「钉钉登录不可用」表示服务端未配置该渠道。
- 会话过期后任意操作会自动跳回登录页。

### 1.2 演示账号（体验推荐）

部署后执行一次 `basalt seed --demo`（幂等）可灌入 12 类演示数据与 6 个测试账号，**密码统一 `Demo@2026`**：

| 账号 | 部门 | 数据权限档 | 用途 |
|---|---|---|---|
| `demo-ceo` | 玄武科技（总部） | 全部数据 | 体验全量视角（如报销单看所有人） |
| `demo-dev` | 技术部 | 本部门 | 对照体验部门级收窄 |
| `demo-sale` | 市场部 | 仅本人 | 对照体验本人数据 |
| `demo-viewer` | —（访客） | 无业务权限 | 体验菜单/按钮按权限收敛 |
| `demo-fin` | 平台组 | 仅本人 | 财务单据本人视角 |
| `demo-tenant` | demo 租户（gov-a） | 租户用户 | 体验租户套餐裁剪 |

演示数据含部门树/岗位/字典/公告/报销（多状态）/发票/预算/付款/公文/合同等，覆盖各页面可直接操作。

### 1.3 界面布局与菜单

- 左侧为导航菜单：**工作台 / 系统管理 / 系统监控** 三组；顶部显示当前页标题、登录名与退出按钮。
- 菜单为**后端动态下发**（按角色过滤）；服务端未播种菜单数据时自动回退内置静态菜单，两者页面行为一致。
- 菜单项按权限点显隐：无权限的页面菜单不显示，直接输入地址访问会进入**「无权访问」提示页**（展示所需权限点）。
- 需要开通权限时联系管理员分配对应角色（见 2.2）。

## 2. 平台管理员

### 2.1 用户管理（/users）

**入口**：系统管理 → 用户管理（权限点 `identity:user:list`）

- **新建用户**（需 `identity:user:create`）：填写用户名（3-32 字符）、密码（≥8 位）、邮箱、租户 ID（留空为平台级用户）。
- **停用/启用**（需 `identity:user:status`）：停用后该用户无法登录。
- **分配角色**（需 `identity:role:manage`）：弹窗多选角色；用户的最终权限 = 全部角色的权限点并集（再经租户套餐裁剪，见 2.5）。
- **导入**（需 `identity:user:create`）：拖入 `.xlsx`，表头须含 `username / email / dept_id / role_codes`；密码列可缺省（系统生成随机口令，需管理员后续重置）。导入结果展示成功数与**逐行失败原因**（如用户名已存在）。
- **导出**（需 `identity:user:list`）：下载 `users.xlsx`；导出文件可直接作为导入模板。

### 2.2 角色管理（/roles）

**入口**：系统管理 → 角色管理（`identity:role:manage`）

- 新建/编辑角色：权限点支持**精确**（`notice:list`）、**前缀通配**（`identity:user:*`）与**全量**（`*`，仅内置 admin 角色持有）。
- 删除角色前需先解除全部用户绑定，否则报错。
- 角色可绑定菜单集合（见 2.3）、携带数据权限档（demo 角色即各档示例）。

### 2.3 菜单管理（/system/menus）

**入口**：系统管理组固定项「菜单管理」（`system:menu:list`；本入口不经动态菜单渲染，确保未播种时也能进入管理）

- 树形展示全部菜单（含停用项与角色绑定计数）；`sort` 升序决定组内顺序。
- **新建**：父级（留空为根/目录节点本身也可作为目录）、名称、路径（须为前端已注册路由，如 `/users`；未注册路径的节点仅作目录不产生页面）、图标（Element Plus 图标名）、权限点（目录节点留空）、排序、启用。
- **编辑/删除**：删除被拒（409）的两种情况——有子节点（先删子项）、有角色绑定（先解绑）。
- **绑定角色**：以菜单为粒度勾选角色；整棵树的批量配置建议在角色侧操作。
- **防成环**：编辑时父级选择器已排除自身子树；服务端同样校验。
- 注意：**隔离模式与库引用一经创建不可在线变更**（防止跨模式数据归属静默变化），见 2.4。

### 2.4 租户管理（/tenants）

**入口**：系统管理 → 租户管理（`tenant:list`）

- 列表展示隔离模式标签（共享表/共享库/独立库）与库引用。
- **新建**（`tenant:create`）：隔离模式三选一——
  - **共享表（shared-schema，默认）**：行级隔离，所有租户同库同表；
  - 共享库独立 schema：存储路由暂未实装，选项置灰；
  - **独立库（dedicated-db）**：需填写**库引用名**（如 `gov-db`，仅填引用名，连接凭据经服务端环境变量 `BASALT_TENANT_DB_*` 注入，**前端不出现任何 DSN/凭据输入**）。
- **编辑**（`tenant:update`）：仅名称与状态可改；隔离模式/库引用创建后**不可变更**，模式变更走「新建租户 + 受控数据迁移」。
- **成员**：查看租户下的用户列表。

### 2.5 租户套餐（/tenant-pkgs）

**入口**：系统管理 → 租户套餐（`tenantpkg:manage`）

- 套餐 = **权限点模板（Perms，生效裁剪）+ 菜单模板（MenuIDs，展示参考）**。
- 新建/编辑：权限点每行一条，支持通配（如 `tenant:*`）；生效语义为「角色权限 ∩ 套餐权限」，平台级用户不受约束，未绑定套餐的租户不受裁剪（向后兼容）。
- **绑定租户**：弹窗内逐租户绑定/解绑；绑定后该租户用户的权限点与菜单自动收窄（E2E 实证：菜单由 2 裁至 1）。
- **在用禁删**：仍有租户绑定的套餐不可删除（409 提示）。

### 2.6 SSO 应用管理（/sso/apps）

**入口**：系统管理 → SSO 应用（`identity:sso:manage`）

- **新建应用**：名称、授权类型（`authorization_code` 授权码 / `client_credentials` 客户端凭证）、回调 URI（每行一个绝对地址；授权码流程必填，与注册值**逐字节精确匹配**）、Scopes、是否公共客户端。
  - 机密客户端：创建成功弹窗**一次性展示 secret**（服务端只存哈希，关闭后不可再查，请立即复制保存）；
  - 公共客户端（SPA/移动端）：无 secret，授权码流程**强制 PKCE（S256）**。
- **轮换 secret**：旧 secret 立即失效，新值同样一次性展示。
- 用户侧授权流程：第三方应用引导用户至 `/#/sso/authorize?...`，用户在确认页看到应用名/申请权限/回调地址后**同意或拒绝**，随后顶层跳转回应用。
- 钉钉登录由服务端环境变量启用（见 1.1），无需在此配置。

### 2.7 在线用户（/online-users）

**入口**：系统监控 → 在线用户（`identity:session:manage`）

- 展示当前在线会话（用户/租户/来源 IP/UA/登录时间），30 秒自动刷新。
- **踢下线**：目标用户全部会话立即失效（后续请求 401），重新登录即恢复。

### 2.8 错误码（/errcodes）

**入口**：系统管理 → 错误码（`errcode:list`）

- 全局错误码注册表（模块 + 错误码唯一），支持按模块过滤；种子已含 8 个模块代表性错误。
- 新增/编辑（`errcode:manage`）：模块与错误码为唯一键，编辑态锁定。

### 2.9 部门与岗位（/org）

双 tab：部门（树形，`org:dept:manage` 可增删改，支持上级选择与排序）、岗位（`org:post:manage`）。部门用于数据权限分档与财务预算归属。

### 2.10 字典管理（/dict）

左侧字典类型、右侧该类型数据（`dict:type:manage` / `dict:data:manage` 控制写操作）；供业务下拉项统一维护。

### 2.11 参数配置（/config）

系统键值参数（`config:manage`）；Key 创建后不可改，改值即时生效。

### 2.12 通知公告（/notices）

面向全员的通知（区别于通知中心的定向消息）；草稿→发布→撤回（`notice:publish`），全员可见已发布公告。

### 2.13 概览（/overview）

登录后首页：我的身份与权限点数、AI 用量（本账期）、审计链完整性校验、已注册模块与 AI 提供方状态。

## 3. 业务用户

### 3.1 审批中心（/approvals）——核心工作台

**四个标签页**：

1. **我的待办**：轮到你的审批任务；每行「通过 / 驳回 / 更多」。
   - **更多**菜单含五项高级操作（均对当前步生效）：
     | 操作 | 语义 | 要点 |
     |---|---|---|
     | 抄送他人 | 知会被选人（可多选，重复抄送幂等） | 被抄送人在「抄送我的」查看，不产生审批负担 |
     | 转办（永久转移） | 审批权整体转给对方 | 本步审批人名单被替换，历史保留 |
     | 委派（本步代办） | 委托对方**仅代审本步一次** | 委托即消耗；你仍可直接审（先到先得）；动作记录「受 X 委托代审」 |
     | 加签（前/后） | 插入一个新签核步 | 前加签=先审新步再回当前步；后加签=当前步完成后先走新步；签核人 1-5 人，或签/会签可选 |
     | 驳回至指定节点 | 退回任意**已过节点**重走 | 轮次 +1（列表与详情显示「第 N 轮」）；已审动作按轮次失效，历史完整保留可审计 |
2. **实例列表**：我发起的 / 全部（需 `workflow:read`）；点「详情」查看步骤条（当前步高亮）、抄送名单、委托列表（生效中/已消耗）与完整动作时间线（含新操作类型与委托标注）。
3. **抄送我的**：被抄送的实例快照（只读知会）。
4. **发起审批**：
   - 选**流程定义**（预置步骤）或手动指定审批人；
   - 三种模式：**会签**（全员通过）、**或签**（任一通过）、**依次**（按选择顺序逐人审批，未轮到者操作无效）；
   - 填写业务号（如 `EXP-2026-001`）与摘要后发起。

### 3.2 流程定义（/wfdefs）

管理员（`workflow:def:manage`）预置审批模板：步骤串行编排，每步选择审批人（多选）与模式（会签/或签/依次）；支持启停用。

### 3.3 公文中心（/documents）

拟稿/收文登记 → 提交审签 → （有 `document:manage` 权限者）归档；「我的/全量」切换（全量需 `document:read`）。

### 3.4 合同管理（/contracts）

登记合同（金额单位为**分**）→ 提交会签 → 生效 →（`contract:manage`）完结；到期前 30 天红色预警；「我的/全量」切换；**导出**按钮下载 xlsx（按当前范围）。

### 3.5 财务中心（/finance）

四个标签页：

- **我的报销**：新建（明细金额单位为**元**，支持多行）→ 提交审批 →（`finance:payment:manage`）付款；**导出**本人报销单。
- 发票登记 / 部门预算 / 付款记录：分别需 `finance:invoice:manage` / `finance:budget:manage` / `finance:payment:manage`；预算页进度条超限变红。

### 3.6 AI 控制台（/ai）

OpenAI 兼容对话（流式输出）；右侧本账期用量环图（超 100% 变红）；有 `ai:quota:manage` 权限者可按租户设置配额（-1 为不限）。

### 3.7 Agent 管理与运行（/agent-defs、/agent-run）

- **Agent 管理**（`agent:read`，写操作 `agent:manage`）：定义名称/模型/系统提示/绑定工具（下拉来自服务端工具注册表，如 `rag.search` 语义检索）/温度/轮数上限。
- **Agent 运行**（`agent:run`）：左侧选 Agent（停用的不可选）与历史会话；输入消息运行，右侧**运行事件**时间线实时展示工具调用过程（调用参数 → 返回摘要）；历史会话可点开回放完整消息（含工具结果）。
- 知识库检索（RAG）目前经 Agent 的 `rag.search` 工具使用（Console 独立知识库管理页规划中）。

## 4. 运维

### 4.1 系统日志（/op-logs）

**入口**：系统监控 → 系统日志（`oplog:read`）

全量 HTTP 请求采集（区别于审计链的合规取证定位）：按模块 / 用户 ID / 状态码段（2xx/4xx/5xx）/ 时间范围过滤，分页浏览。注意条目落地有 ≤100ms 异步窗口，刚发生的请求稍候可见。

### 4.2 运行监控（/op-metrics）

90 秒滑动窗口实时快照（30 秒自动刷新）：QPS、错误率（5xx+429，>5% 红色预警）、P50/P95/P99 延迟、QPS 趋势折线（本页采样）；进程指标（Goroutines/堆内存/GC）；采集器状态（dropped>0 表示背压丢弃）。

### 4.3 定时任务（/jobs）

- **内置任务**：进程内函数调度，不可删除（无删除按钮）。
- **动态任务**（`job:manage`）：注册 HTTP 回调任务——任务 ID（唯一）/名称/调度（**cron 五段表达式**或固定间隔秒，二选一）/回调 URL/方法（GET/POST/PUT）/负载。
- 每行可启停、立即执行、看**日志**（执行记录分页，含失败原因与耗时）。

### 4.4 文件管理（/files）

上传（`file:upload`，单文件 ≤32MB）/下载/删除（`file:delete`）；**存储列**标识文件所在后端（本地 / S3）——多云驱动切换后旧文件按标记路由，混合存量均可访问。

### 4.5 通知中心（/notify）

四标签页（`notify:list`，写操作 `notify:manage`）：

- **模板**：三渠道（短信/邮件/站内信）共用，`{{var}}` 变量渲染，未匹配变量保留原样；
- **邮件账号 / 短信渠道**：元数据落库，**密码与 AccessKey/Secret 经服务端环境变量注入**（`BASALT_NOTIFY_SMTP_PWD_*` / `BASALT_NOTIFY_SMS_*`），前端无任何凭据输入；
- **发送日志**：按渠道过滤 + 分页；失败日志可**手动重发**（系统不自动重试）；
- 右下角「发」按钮：发送测试（选渠道/模板/接收者/变量 JSON）。

### 4.6 审计链（/audit）

防篡改结构化审计（合规取证）：链完整性校验标签 + 事件流查询（按模块过滤）。与系统日志的分工：审计链回答「谁在何时改了什么且不可抵赖」，系统日志回答「服务最近表现如何」。

## 5. 常见问题（FAQ）

**Q1：如何给新部门配置审批人？**
系统管理 → 部门与岗位新建部门；流程定义（/wfdefs）中对应步骤选择该部门成员为审批人（或直接在发起审批时手选）。若需按部门收敛可见数据，为角色设置对应数据权限档。

**Q2：如何体验数据权限差异？**
用演示账号对照登录（密码均 `Demo@2026`）：`demo-ceo`（全部数据）→ 报销单看所有人；`demo-dev`（本部门）→ 只看技术部；`demo-sale`/`demo-fin`（仅本人）→ 只看自己创建的单据。管理员为角色设置 DataScope 即生效。

**Q3：如何配置 SMTP 发邮件通知？**
通知中心 → 邮件账号新建（账号名如 `main`）；运维在服务端设置环境变量 `BASALT_NOTIFY_SMTP_PWD_MAIN` 后重启；然后建邮件模板 → 右下角「发」测试 → 查看发送日志确认 sent。

**Q4：如何让某角色只看到部分菜单？**
菜单管理 → 选中菜单「绑定角色」勾选目标角色；或反向在角色绑定接口配置整棵集合。菜单可见性同时受权限点过滤（节点绑定的权限点用户未持有时不下发）。

**Q5：租户隔离模式选错了能改吗？**
不能。隔离模式与库引用创建后不可在线变更（防止既有数据归属静默变化）；正确做法是新建目标模式租户 + 受控数据迁移。

**Q6：SSO 应用的 secret 丢了怎么办？**
应用列表 → 轮换：旧 secret 立即失效，新 secret 一次性展示，立即复制并更新到应用侧配置。

**Q7：用户导入的表格格式？**
点「导出」下载的 users.xlsx 即模板：表头 `username / email / dept_id / role_codes`（+可选密码列）。密码留空时系统生成随机口令，导入后请为用户重置。

**Q8：踢下线是立即生效吗？**
是。被踢用户的所有已签发令牌立即失效（用户级吊销时间戳校验），其下一次请求即 401；重新登录可恢复。

**Q9：审批驳回到错误的节点了怎么办？**
当前步审批人可用「驳回至指定节点」退回到任意已过节点重走（轮次 +1）；完整动作历史保留在详情中可审计，不可删除。

**Q10：委派和转办有什么区别？**
**转办**=审批权永久转移给对方（你退出本步）；**委派**=委托对方仅代审本步一次（你的名义保留，仍可自己抢先审）。按钮与对话框文案已作区分。

**Q11：Agent 运行报「no AI provider registered」？**
服务端未配置 AI 提供方（`BASALT_AI_PROVIDER_URL/KEY/MODEL`）。定义管理与历史功能不受影响；配置后运行与 SSE 事件即恢复。

**Q12：如何导出合同/报销单？**
合同管理 →「导出（我的/全量）」；财务中心 → 我的报销 →「导出」。均为 xlsx，金额已按元两位小数格式化。

**Q13：登录后菜单很少或页面提示无权访问？**
权限点由角色授予：联系管理员在角色管理为你的角色添加权限点（支持 `模块:*` 通配），或检查所在租户是否被套餐裁剪（租户套餐页可查绑定）。

**Q14：动态任务注册后多久生效？什么时候触发？**
注册即生效并开始调度；cron 任务按表达式触发（列表「调度」列显示表达式，下次触发时间见服务端调度器）；「立即执行」可手动触发一次，执行结果在「执行日志」标签页查看。
